# Proyecto de Machine Learning
## Modelo de clasificiación con Python 
### Bootcamp del Cientifico e Datos Daniel Roman 2026.
Este proyecto es para la empresa textilera, se desarrolla un modelo de clasificación para saber si el cliente comprara o no en los proximos en 3 meses.

Se fundamenta en un modelo de regresión logística.

##Paso a paso para ejecutar el proyecto:
1. ETL Modaviva con SQL
2. EDA
3. Modelo de clasificación 
4. Evaluación
5. Producción (API)
6. Desarrollo app streamlit
